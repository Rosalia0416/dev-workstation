## 10. Dockerfile 기반 커스텀 이미지 + 포트 매핑 ### 10-1. 베이스 이미지 선택 - **방식 (A)**: 웹 서버 베이스 이미지 활용 + 정적 콘텐츠 교체 - **베이스**: `nginx:1.27-alpine` (Docker Hub 공식 NGINX 이미지, alpine으로 경량화) ### 10-2. 소스 구조 ``` dev-workstation/ ├── Dockerfile └── app/ └── index.html ``` ### 10-3. Dockerfile ```dockerfile FROM nginx:1.27-alpine LABEL maintainer="Rosalia0416" \ description="Custom NGINX image for dev-workstation mission" COPY app/ /usr/share/nginx/html/ EXPOSE 80 HEALTHCHECK --interval=30s --timeout=3s \ CMD wget -q -O /dev/null http://localhost/ || exit 1 ``` ### 10-4. 커스텀 포인트와 목적 | 지시어 | 목적 | |---|---| | `FROM nginx:1.27-alpine` | 검증된 공식 웹 서버를 베이스로 사용, alpine으로 이미지 용량 절감 | | `LABEL` | 관리자·설명 등 이미지 메타데이터 기록 | | `COPY app/ ...` | NGINX 기본 페이지를 내 정적 콘텐츠로 교체 | | `EXPOSE 80` | 컨테이너가 80 포트를 사용함을 명시 (문서화) | | `HEALTHCHECK` | 30초마다 웹 응답을 점검해 컨테이너 상태를 `healthy`로 표시 | ### 10-5. 빌드 ```bash PS> docker build -t my-web:1.0 . (빌드 출력 붙여넣기) PS> docker images IMAGE ID DISK USAGE CONTENT SIZE EXTRA hello-world:latest c567b231f656 25.9kB 9.49kB U my-web:1.0 52de41df12ee 73.6MB 21MB ubuntu:latest 6a06111c3b0a 163MB 45.9MB U ``` ### 10-6. 실행 (포트 매핑) ```bash PS> docker run -d --name my-web -p 8081:80 my-web:1.0 PS> docker ps -a CONTAINER ID IMAGE COMMAND CREATED STATUS PORTS NAMES a0af17d2fee3 my-web:1.0 "/docker-entrypoint.…" 15 minutes ago Up 15 minutes (healthy) 0.0.0.0:8081->80/tcp, [::]:8081->80/tcp my-web ``` - `-p 8081:80` = 호스트(내 PC) 8081 포트 → 컨테이너 80 포트로 연결 - **포트 매핑이 필요한 이유:** 컨테이너는 격리된 네트워크에서 실행되므로, 호스트 포트와 연결하지 않으면 외부(브라우저)에서 접근할 수 없음 - `(healthy)`: HEALTHCHECK 통과 ### 10-7. 접속 확인 ```bash PS> curl.exe http://localhost:8081 Dev Workstation ...
